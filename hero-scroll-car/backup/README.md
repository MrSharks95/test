# Sauvegardes pour le retour arrière

Fichiers du thème de test tels qu'ils étaient avant les nouveautés. Pour revenir en arrière,
recoller le contenu dans l'éditeur de code du thème (ou le renvoyer par l'API) :

- `templates-404.json` : gabarit 404 d'origine du thème Heritage (section `main-404`).
- `templates-index.before-nouveautes.json` : page d'accueil avant l'ajout du bloc « Effets visuels »,
  du bouton « tout le kit », et des sections « Avant / après » et « Avis clients ».
- `settings_data.before-dark.json` : réglages du thème (schémas de couleurs) avant le passage en sombre,
  s'il a été appliqué.
- `templates-product.json` : gabarit produit d'origine du thème Heritage (section `main-product`), avant
  « Sans page produit ».
